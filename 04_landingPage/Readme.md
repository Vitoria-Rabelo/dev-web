# Atividade Prática: Crie sua Página Web
**Disciplina:** Desenvolvimento Web · Atividade Prática 01  
**Modalidade:** Individual  
**Entregáveis:** `index.html` + `index.css`  
**Tema:** Livre

---

## Descrição

O aluno deverá desenvolver uma **página inicial (`index.html`)** sobre um tema de sua escolha — pode ser um portfólio pessoal, uma série, personagem fictício, banda de música, anime, cidade turística, jogo, etc. O conteúdo pode ser real ou gerado por IA. Devem ser criados **exatamente dois arquivos**: `index.html` e `index.css`.

---

## 1. Estrutura da Página

A página deve ser composta pelos seguintes elementos:

- Topo com o **nome do site** ou logomarca
- **Menu de navegação** com ao menos 4 links dispostos horizontalmente
- **Favicon** (ícone de preferência) configurado na página
- **Corpo principal** com o conteúdo do site
- **Rodapé** contendo: nome do aluno, matrícula, nome da universidade e e-mail institucional

---

## 2. Conteúdo do Corpo

O corpo do site deve ter, obrigatoriamente:

- No mínimo **4 parágrafos** de conteúdo
- No mínimo **1 imagem** (com legenda)
- **Cabeçalho** para cada parágrafo
- Ao menos uma **lista não ordenada**
- Ao menos uma **tabela** com mínimo de **3 linhas** e **2 colunas**

---

## 3. Requisitos de HTML

### No `<head>`

- Meta de **autoria** (`name="author"`) e **codificação** (`charset="UTF-8"`)
- Tag `<title>` com o título da página
- Importação do arquivo CSS externo via `<link rel="stylesheet">`

### Tags Semânticas Obrigatórias

Devem ser utilizadas as seguintes tags semânticas:

`<nav>` · `<main>` · `<article>` · `<footer>` · `<section>`

### Imagens

- Atributo `alt` em todas as imagens
- Legenda via `<figure>` e `<figcaption>`

### Tabelas

As tabelas devem ser construídas com tags semânticas:

`<thead>` · `<tbody>` · `<tfoot>` · `<th>` · `<td>`

---

## 4. Requisitos de CSS

- Escrito em arquivo **separado** (`index.css`) e importado no HTML
- Estilizar **fontes, cores e espaçamentos**
- **Cores distintas** para topo, corpo e rodapé
- Utilizar **Flexbox** para organização do layout
- **Pseudo-classes** nos links (`:hover`, `:visited`, etc.)
- Ao menos **3 classes** e **3 IDs** definidos no CSS

> Pesquise como fazer a utilização do Google Fonts ou uma fonte da web para enriquecer a tipografia do site.
